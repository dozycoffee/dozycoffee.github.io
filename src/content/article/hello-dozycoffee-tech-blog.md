안녕하세요, 이곳은 저희가 서비스를 만들면서 배운 것과 고민한 과정을 기록하는 기술블로그입니다.

# 왜 블로그를 시작했나요?

개발하다 보면 삽질 끝에 얻은 해결책, 여러 선택지 사이에서 내린 결정, 만들고 나서야 알게 된 교훈이 쌓입니다. 이런 이야기는 시간이 지나면 팀 안에서도 금세 잊히곤 합니다. 기록으로 남겨 두면 저희에게는 나중에 돌아볼 자료가 되고, 비슷한 문제를 만난 다른 개발자에게는 작은 도움이 될 수 있다고 생각했습니다.

# 어떤 글을 쓰나요?

글은 세 가지 카테고리로 나뉩니다.

- **Learn**: 자유롭게 공부한 내용 정리
- **Tech**: 프로젝트에 사용한 기술을 익히고 정리한 글
- **Project**: 도지커피에서 진행한 프로젝트의 배경, 설계, 회고

카테고리는 홈 화면의 탭으로 골라 볼 수 있고, 상단의 검색 버튼으로 제목·설명·태그를 검색할 수 있습니다.

# 이 블로그는 이렇게 만들었어요

이 블로그 자체도 하나의 작은 프로젝트입니다.

- [Astro](https://astro.build)로 만든 정적 사이트이며, 글은 Markdown/MDX 파일로 관리합니다.
- GitHub 저장소에 글을 PR로 올리고, 머지되면 GitHub Actions가 빌드해서 GitHub Pages에 자동으로 배포합니다.
- 글쓰기 방법은 저장소의 `CONTRIBUTING.md`에 정리되어 있습니다.
